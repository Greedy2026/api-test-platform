接口自动化测试平台架构
========================

  ┌──────────────┐   HTTP/JSON    ┌──────────────────┐
  │   浏览器 SPA  │ ─────────────> │  Spring Boot 平台 │
  │ (index.html) │ <------------- │  JWT 鉴权 + REST  │
  └──────────────┘                └────────┬─────────┘
                                           │ 异步任务
                              ┌────────────┴────────────┐
                              │      ExecutionService    │
                              │  导出用例 JSON -> 调起进程 │
                              └────────────┬────────────┘
                                           │ stdin/stdout 文件协议
                              ┌────────────┴────────────┐
                              │    Python 执行引擎        │
                              │   engine/runner.py       │
                              │  发起 HTTP 请求 + 断言     │
                              └────────────┬────────────┘
                                           │ 结果 JSON
                              ┌────────────┴────────────┐
                              │  结果入库（H2/MySQL）      │
                              │  ExecutionRun/CaseResult │
                              └─────────────────────────┘

  另有 ScheduleScanner 每 30 秒扫描到期用例集，自动触发执行（scheduled=true）。
